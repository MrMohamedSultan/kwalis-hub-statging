## Before sharing SECURITY.md with the client

1. Apply 195, 200 and 201 (after review) and deploy the app.
2. Set `DEMO_ACCOUNT_PASSWORD` (or leave demo mode off) and the GoTrue hook env vars.
3. Run the backup / restore steps of `docs/BACKUP_RESTORE.md` once on the server.
4. The client's own information-security policy files are not in the repo:
   compare them with SECURITY.md §7 when they are shared.
